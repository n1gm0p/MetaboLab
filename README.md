# MetaboMap

Интерактивная научная карта метаболизма человека для углублённого изучения медицинской биохимии.
Начните с любого вещества и проследите его превращения через реакции, ферменты, компартменты и пути.

## Возможности

- **Двудольный граф** (Cytoscape.js): узлы-вещества и узлы-реакции, направленные рёбра субстрат → реакция → продукт, стехиометрия на рёбрах. Прямых связей «вещество → вещество» нет.
- **Компартменты**: вещество привязано к компартменту (глюкоза в цитозоле ≠ глюкоза в просвете ЭПР); между компартментами — только транспортные реакции.
- **Кофакторы** (ATP, NAD⁺, H₂O и др., курируемый список по ChEBI): дублируются у каждой реакции, показываются общим узлом или скрываются.
- **Единый поиск** по русским и международным названиям, синонимам ChEBI, аббревиатурам, генам, EC-номерам, ChEBI/Rhea ID. Результаты разделены по типам; у вещества видны формы по компартментам.
- **Карточки** вещества (реакции образования и превращения раздельно, пути, другие компартменты, ChEBI-определение, SMILES, InChIKey), реакции (уравнение с коэффициентами, фермент, гены, EC, кофакторы катализатора, регуляция, обратное превращение, описание и литература Reactome), фермента и пути (подпути, вычисленные входы/выходы, связанные пути).
- **Маршруты между веществами**: k кратчайших простых путей (Yen + Дейкстра) с учётом направления и компартментов; отдельный «топологический» режим, явно помеченный как не биохимический. Для каждого шага показаны косубстраты и сопутствующие продукты.
- **Личное пространство**: избранное и заметки (IndexedDB), экспорт/импорт JSON, восстановление последней карты, ссылки на объект вида `/#metabolite:R-ALL-70113`.
- **Самопроверка**: скрывает названия веществ, ферментов, EC и описания с раскрытием по нажатию.
- **iPad/телефон и PWA**: жесты масштабирования, увеличенные зоны нажатия, нижний лист карточки, манифест, офлайн-кэш через service worker.

## Запуск локально

Требуется Node.js 20+ (проверено на 22.16).

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # Vitest: граф, маршруты, поиск, пользовательские данные, проверка базы
npm run typecheck  # tsc --noEmit
npm run build && npm start
```

База уже сгенерирована и лежит в `public/data/`. Обновить её из источников:

```bash
npm run import:reactome         # Reactome + ChEBI (≈2.5 мин при пустом кэше)
npm run import:reactome:fast    # без ChEBI (без определений, SMILES и синонимов)
node scripts/import/import-reactome.mjs R-HSA-70171   # только выбранные пути
```

Ответы API кэшируются в `scripts/import/.cache/` (в git не попадает).

## Деплой на Vercel

Проект — обычное приложение Next.js без сервера и базы данных: все данные статические.

1. Загрузите репозиторий на GitHub.
2. На vercel.com: **Add New → Project**, импортируйте репозиторий. Framework Preset определится как Next.js; переменные окружения не нужны.
3. **Deploy**. Либо из терминала: `npx vercel` (предпросмотр) и `npx vercel --prod`.

После переимпорта базы достаточно закоммитить `public/data/` и задеплоить заново.

## Архитектура

```
scripts/import/            изолированный импортер (Node, без зависимостей)
  import-reactome.mjs      Reactome ContentService → нормализация → public/data
  lib/http.mjs             кэш на диске, повторы, ограничение параллелизма
  curation/currency.mjs    курируемые кофакторы (по ChEBI)
  curation/ru-names.mjs    курируемые русские названия (по ChEBI / Reactome / GO / EC)
public/data/dataset.json   граф (≈4 МБ, gzip ≈0.6 МБ), проверяется Zod при загрузке
public/data/details/*.json 64 шарда описаний, литературы и данных ChEBI; грузятся по требованию
src/lib/model              типы предметной области и Zod-схемы (с проверкой синхронности на этапе компиляции)
src/lib/data               индекс, детали, вычисляемые свойства путей, демо-набор
src/lib/graph              построение двудольного графа, окрестности, поиск маршрутов
src/lib/search             нормализация и ранжирование поиска
src/lib/user               модель и репозиторий пользовательских данных (IndexedDB)
src/components             клиентские компоненты; Cytoscape грузится только в браузере (next/dynamic, ssr: false)
```

Серверные части (layout, page, manifest, иконки) не используют `window`; карта, состояние и хранилище — клиентские компоненты (`"use client"`).

Пользовательские записи содержат `updatedAt` и метки удаления, поэтому синхронизация между устройствами подключается через новую реализацию интерфейса `UserDataRepository` без изменения модели.

## Источники данных и ограничения

| Источник | Что используется | Лицензия / доступ |
|---|---|---|
| **Reactome** (релиз 97), раздел *Metabolism* R-HSA-1430728, *Homo sapiens* | реакции, стехиометрия, компартменты, катализаторы (гены, EC, кофакторы в составе), регуляция, иерархия путей, описания, литература | CC BY 4.0, открытый REST API |
| **ChEBI** через EBI OLS4 | определения, SMILES, InChIKey, синонимы | CC BY 4.0 |
| **Rhea** | только перекрёстные ссылки из Reactome | CC BY 4.0 |
| **KEGG** | только идентификаторы из Reactome (ссылки) | API бесплатен лишь для академического использования; массовая загрузка требует лицензии, поэтому данные не загружаются |
| **MetaCyc** | не используется | полный доступ по подписке |
| **PubChem** | не используется в текущей версии | общественное достояние; можно добавить в импортер |

Объём импорта: **2378 реакций** (2044 превращения, 268 событий black-box, 55 связываний, 9 диссоциаций, 2 полимеризации), **3195 участников** по компартментам (1314 уникальных ChEBI), **1408 катализаторов**, **336 путей**, **39 компартментов**, 4028 записей с описаниями. У 247 реакций есть ссылка на обратное превращение (59 указаны в Reactome, 188 найдены импортёром по совпадению основных участников). Русские названия: 651 участник, 112 путей (включая все пути трёх верхних уровней иерархии), 87 катализаторов по названию EC-активности.

Ограничения:

- Это **не полная карта метаболизма человека**, а ручная курируемая база Reactome. Часть реакций из Rhea, KEGG, MetaCyc и Recon3D отсутствует; болезнетворные варианты исключены. Реакции, выведенные по ортологии из других видов, помечены в источниках.
- Reactome моделирует каждое направление отдельной реакцией. Флаг «обратима» не выставляется; обратное превращение показывается ссылкой, если пара реакций найдена в данных.
- Без атомного картирования шаг маршрута «A → B» означает лишь, что A — субстрат, а B — продукт одной реакции. Ранжирование маршрутов эвристическое: штрафы за black-box события, дополнительные косубстраты и несовпадение числа атомов C в обменных реакциях. Косубстраты всегда показываются.
- Русские названия курируются вручную (`curation/ru-names.mjs`); без перевода показывается международное название.
- Тексты описаний — оригинальные тексты Reactome на английском; приложение ничего не генерирует.
